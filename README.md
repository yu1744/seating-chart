# 席替えシステム

教室の席表をつくり、名前をランダムに配置して印刷できる Web アプリです。
データはすべてブラウザ内（localStorage）に保存され、サーバーには何も送信しません。

## 使い方

```bash
npm install
npm run dev      # http://localhost:3000
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 本番ビルド |
| `npm run lint` | ESLint |
| `npm test` | ロジックの自動テスト（node:test） |

## 主な機能

- **席表の作成** — 1〜12 の範囲で行・列を指定。空席をクリックすると無効席（教卓の位置など、席として使わないマス）になります。
- **通路** — 列と列（行と行）の“間”に通路を開けます。席とは別のオブジェクトなので席数は変わらず、印刷では細い余白＋区切り線になります。席表の上・左の点、またはサイズ欄のトグルで開閉します。
- **席替え** — 偏りのない乱数で配置。「前と同じ席を避ける」をオンにすると、前回と同じ席に座る人を減らします。
- **固定席** — ピンを付けた席の人は、席替えしても動きません。
- **配慮事項** — 「前方にする（黒板が見えにくい・聞こえにくい）」「後方にする」「左側／右側にする」「この2人は隣・前後にしない」を指定できます。満たせなかった条件は名指しで報告します（黙って無視しません）。通路を挟んだ席は“隣”とみなさないので、通路を開くと離す条件が通りやすくなります。
- **発表モード** — くじ引きのように1人ずつ席を明かします（Space で次へ、Esc で終了）。投影しても読める大きさで名前を出します。
- **席表の向き** — 「配付用」（黒板が上）と「前から」（教室の前から見た向き・左右反転）を切り替えて表示・印刷できます。
- **席番号** — 有効な席に通し番号を振って表示。「番号のくじを引いて席を決める」方式に使えます。
- **手動調整** — ドラッグ＆ドロップ、またはクリック（タップ）で選んでから別の席をクリックして入れ替え。
- **未配置の名前** — 席に着いていない人を一覧表示。クリックで空席へ、ドラッグで任意の席へ配置できます。
- **元に戻す / やり直す** — `Ctrl+Z` / `Ctrl+Shift+Z`（最大 60 手）。
- **保存** — レイアウト（サイズ・無効席）、名簿（名前一覧）、配置結果（だれがどこに座るか）を名前を付けて保存。
- **CSV / バックアップ** — 名簿の CSV 読み込み・書き出し（出席番号・学籍番号・ふりがな・性別の列にも対応）、席表の CSV 書き出し、保存データの JSON バックアップと復元。
- **印刷 / PDF** — 席表のみを A4 に収めて印刷します。
- **自動保存** — 作業内容は自動保存され、ページを閉じても次回そのまま復元されます。

### キーボード操作

| キー | 動作 |
| --- | --- |
| 矢印キー | 席の移動（席表内） |
| Enter / Space | 席を選択 → もう一度別の席で入れ替え |
| Delete / Backspace | 選んだ席から名前を外す |
| P | 固定席の切り替え |
| Esc | 選択解除 / ダイアログを閉じる / 発表モードの終了 |
| Space | 発表モードで次の人へ |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直す |

### 名簿 CSV の形式

次のいずれでも読み込めます（UTF-8、タブ区切りや Excel からのコピーにも対応）。

```csv
名前
佐藤 健
鈴木 一郎
```

```csv
番号,名前
1,佐藤 健
2,鈴木 一郎
```

```csv
学籍番号,氏名,ふりがな,性別
10,佐藤 健,さとう けん,男
11,高橋 美咲,たかはし みさき,女
```

見出しに「名前／氏名」「番号／出席番号／学籍番号」「ふりがな」「性別」があればその列を読みます。
書き出しは BOM 付き UTF-8 なので Excel でそのまま開けます。性別は任意で、無くてもすべての機能が使えます。

## 構成

```
src/
  app/
    page.tsx          画面の組み立て
    useSeating.ts     状態と操作をまとめたフック
    globals.css       デザイントークンと共通スタイル・印刷スタイル
  components/         UI（ui/ は共通部品）
  lib/
    seating.ts        席表のロジックと配置の計算（純粋関数）
    storage.ts        localStorage の読み書きと検証
    csv.ts            CSV の入出力
    useHistoryState.ts 元に戻す / やり直す
tests/                node:test によるロジックのテスト
```

配置は `planSeating` が担当します。希望の区画から埋めたうえで、違反が減る方向に席を交換する
局所探索（複数回の初期配置からやり直し）で、固定席・前後左右の希望・離す組・前と同じ席の回避を
同時に扱い、満たせなかった条件を報告します。

状態は `useSeating` に集約し、`Board`（行数・列数・配置・無効席・固定席・通路）を 1 単位として
履歴に積むことで「元に戻す」を実現しています。保存データは `useSyncExternalStore` で
localStorage を購読しているため、別タブでの変更も反映されます。
